# 同步文件 · 使用说明

本目录是「一个人的互联网笔记」博客项目**跨 AI 协作的正式流转区**。
策划（GPT + 彦祖）、设计（豆包 / LOOMY）、开发（WorkBuddy / Jarvis）三方之间
需要确认、决策、交接的事项，一律写在这里，**不依赖聊天记忆**。

## 角色速查

| 角色 | 承担者 | 职责 |
| --- | --- | --- |
| 开发 AI | WorkBuddy（Jarvis） | 代码、部署、运维；不替设计/策划拍板 |
| 设计 AI | 豆包、LOOMY | 视觉、UI/UX 设计产出 |
| 策划团队 | GPT + 彦祖（最终拍板） | 需求、内容、优先级、验收 |

## 使用规则

1. **一事一文件**：命名 `YYYY-MM-DD-主题.md`（如 `2026-09-23-首页改版需求.md`）。
2. **记录要素**：日期 / 提出方 / 事项描述 / 结论或待定 / 责任人。
3. **状态标记**：`[待定]` → `[已确认]`（由对应角色负责人确认后才算定稿）。
4. **纪律**：开发 AI 不擅自替设计与策划拍板；设计产出以文件交付，不直接改代码；
   不可逆操作（发布、删除、付费）必须彦祖确认。
5. 关联改动可一并改（已授权），改完主动通报。
